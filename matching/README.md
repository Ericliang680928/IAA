# IAA 交朋友大冒險 · 三輪配對工具

- 網址（上傳後）：https://ericliang680928.github.io/IAA/matching/
- 單檔離線工具（index.html），無伺服器；資料存在使用者瀏覽器 localStorage。
- 名單來源：內建預設會友名單，或管理端「☁️ 從雲端匯入」串 Google 試算表（報名表單回應）。
- 隱私：本工具與名單不含手機、地址；報名試算表僅放媒合欄位。

## 更新方式
直接用新版 index.html 覆蓋本資料夾同名檔案即可（GitHub 網頁 → Add file → Upload files → 拖入 → Commit）。
